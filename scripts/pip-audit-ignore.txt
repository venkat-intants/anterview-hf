# --- ecdsa 0.19.2 — NO FIX EXISTS ------------------------------------------
# Minerva-class timing attack on ECDSA signing. Reached only through
# python-jose, which is the platform's JWT library (shared/auth/jwt.py:21).
# NOT exploitable here: every issue/verify path is HS256 (symmetric) —
# issue_access_token/verify_access_token default algorithm="HS256" and pass a
# single algorithm to jose, which also blocks algorithm-confusion. No ES*
# algorithm is used anywhere, so the vulnerable code never runs.
# Unblock: an ecdsa release with a fix, or migrating fully to PyJWT.
PYSEC-2026-1325
